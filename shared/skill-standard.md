# スキルの作成と配置

## 配置

- 本体は `<AI名>/skills/<スキル名>/` に置く。名前は小文字の英数字とハイフンにする。
- Codex用は `SKILL.md` を編集元とし、必要なら `agents/openai.yaml` を同じフォルダに置く。
- 各スキルの `README.md` に用途、必要な接続、導入方法、入力例、検証状況を書く。
- 共通の運用文書は `shared/`、作成用ひな形は `templates/` に置く。
- `scripts/` や `references/` はそのスキルで必要になったときに追加する。

## 内容と公開前の確認

適用条件、期待する成果、必要な入力、外部操作の範囲を具体的に書く。指定が足りない場合や、外部操作が部分成功した場合の扱いも、用途に必要な範囲で定める。

公開前に本体の形式とREADMEのリンク・導入手順を確認する。秘密情報や個人のローカルパスを含めない。実行していない検証は未実施と記載する。

スキルを追加・移動したら、ルートREADMEの一覧と導入手順も更新する。他のAIへの対応は、その環境で利用できることを確かめてから案内する。
