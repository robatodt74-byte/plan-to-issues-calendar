# Codexスキルの作成用テンプレート

`codex/skills/<スキル名>/SKILL.md` を新規作成し、次の内容を用途に合わせて書き換えます。このファイル自体はインストール対象ではありません。

```markdown
---
name: your-skill-name
description: 何をするスキルか、どんな依頼で使うかを具体的に書く。
---

# スキル名

期待する成果と必要な入力を書く。

## 手順

用途に必要な判断と作業手順を書く。

## 確認と報告

結果の確認方法と、完了・未完了をどう伝えるかを書く。
```

同じフォルダに利用者向けの `README.md` を用意し、次の情報を記載します。

- 機能と必要な環境・接続先
- 導入方法と編集対象のファイル
- 入力例と期待する結果
- 実施済みの検証と未実施の検証

完成後、ルートREADMEのスキル一覧に追加します。
